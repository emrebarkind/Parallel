# Roadmap

Parallel will be developed step by step, starting from a simple open-source MVP and moving toward a more complete vending operations intelligence layer.

## v0.1 — Data to Report

Goal: Generate a basic Weekly Decision Report from CSV data.

- CSV import
- Stockout risk calculation
- Waste / slow mover risk calculation
- Basic service priority score
- Markdown report generation

## v0.2 — Recommendation Engine

Goal: Improve the quality and structure of recommendations.

- Structured recommendation objects
- Better explanation text
- Product-level performance analysis
- Category-level insights
- HTML report export

## v0.3 — Operator Feedback

Goal: Create a feedback loop between operators and recommendations.

- Approve / reject / edit recommendation status
- Recommendation history
- Feedback log
- Outcome tracking

## v0.4 — Dashboard

Goal: Make the MVP easier to use and present.

- Simple web interface
- Machine overview
- Risk summary cards
- Weekly report preview
- Export options

## v0.5 — API Ready

Goal: Prepare the system for integrations.

- FastAPI backend
- Upload endpoint
- Recommendation endpoint
- Report generation endpoint
- Integration-ready architecture

## Future Direction

After the MVP is validated, Parallel can expand toward:

- Live telemetry integrations
- Operator system integrations
- Advanced route prioritization
- Product assortment intelligence
- Sustainability and waste reporting
- Hosted cloud version for operators
